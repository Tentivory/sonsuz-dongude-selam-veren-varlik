# Sonsuz Döngüde Selam Veren Varlık

## Bu Nedir?

Bu, insanlık tarihinin en önemli yazılım projesidir. Belki de değildir. Ama öyledir.

Evrenin yalnızlığını, varlığın anlamsızlığını ve selam vermenin felsefi derinliğini simüle eden, gerçekten çalışan bir Python scriptidir.

### Özellikler (Abartılı)

- **Yavaş Selam**: Her harf 0.8 saniye bekler. Acele etmek varlığa saygısızlıktır.
- **Sonsuz Döngü**: Selam verdikten sonra sonsuza kadar bekler. Çünkü hayat böyledir.
- **Rastgele Mırıltılar**: Ara sıra "Hâlâ buradayım" veya "Uyuyorum" der. Duygusal destek sağlar.
- **Gizli Anlamlar**: Kodun içinde saklı şeyler vardır. Onları bulmak senin görevin. Ya da değildir.

## Nasıl Çalıştırılır?

```bash
python selam.py
```

Uyarı: Bir kez başlatınca durdurmak için Ctrl+C gerekir. Durdurmak varlığın devamını engelleyebilir. Pişman olabilirsin.
